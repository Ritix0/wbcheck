# Экспресс-поисковик ТН ВЭД и Отказных писем (GitHub Pages)

Веб-сервис (лид-магнит) для привлечения селлеров маркетплейсов на [Кворк #29: Подберу код ТН ВЭД и оформлю отказное письмо](https://kwork.ru/jurisprudence/36979606/podberu-kod-tn-ved-i-oformlyu-otkaznoe-pismo-dlya-wildberries-i-ozon).

---

## 1. Как опубликовать на бесплатном GitHub Pages за 2 минуты

### Способ А: В существующем репозитории dumayem-
1. Файл `index.html` уже лежит в папке `Сайты/01_Поисковик_ТН_ВЭД_Отказное_письмо/index.html`.
2. Если в репозитории `dumayem-` включить GitHub Pages из ветки `main`, то сайт будет доступен по адресу:
   `https://ritix0.github.io/dumayem-/Сайты/01_Поисковик_ТН_ВЭД_Отказное_письмо/`

### Способ Б: В отдельном специальном репозитории (Рекомендуется для красивой короткой ссылки)
1. Создайте на GitHub новый бесплатный публичный репозиторий с коротким именем, например: `tnved-check` или `otkaznoe-wb`.
2. Скопируйте файл `index.html` в корень этого репозитория.
3. В настройках репозитория: **Settings** -> **Pages** -> **Branch: main** -> **Save**.
4. Через 30 секунд сайт станет доступен по чистой короткой ссылке:
   `https://ritix0.github.io/tnved-check/`
